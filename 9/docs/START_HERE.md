# PVZ.FLOW — быстрый старт

## Запуск

1. Распакуйте архив в любую папку (например `C:\PVZ_FLOW`).
2. Дважды щёлкните **`START_PVZ_FLOW.cmd`**.
3. Приложение откроется в браузере.

Устанавливать Node.js, npm или какие-либо зависимости **не нужно** —
Node уже вложен в папку `runtime`.

## Если браузер не открылся

Адрес всегда печатается в окне запуска, например:

```
PVZ.FLOW запущен
http://localhost:8785/
```

Откройте его вручную. Скопируйте адрес из окна — он может отличаться от
`8783`, если этот порт занят другой программой.

## Как закрыть

Просто закройте окно запуска. Данные сохраняются автоматически при каждой
операции, поэтому закрывать браузер не обязательно.

## Что где лежит

| Папка | Содержимое |
|---|---|
| `app\dist` | интерфейс приложения |
| `data\PVZ_FLOW_DATA.sqlite` | **все данные** — единственный источник истины |
| `data\backups` | автоматические и ручные резервные копии |
| `server` | локальный сервер и вся бизнес-логика |
| `runtime\node.exe` | встроенный Node.js |
| `docs` | эта документация и порядок обновления |

## Резервное копирование

Данные лежат в одном файле. Достаточно скопировать
`data\PVZ_FLOW_DATA.sqlite`, но **при выключенном приложении**,
иначе не будут скопированы последние изменения из журнала WAL.

Надёжнее использовать встроенную кнопку резервного копии в разделе
«Настройки»: копия создаётся через SQLite Backup API и всегда
согласованна. Подробности — в `UPDATE_AND_RECOVERY.md`.
