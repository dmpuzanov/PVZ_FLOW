# PVZ.FLOW — сборка переносного пакета для Windows

Скрипт собирает готовый к запуску каталог из рабочего дерева.

## Запуск

```powershell
powershell -ExecutionPolicy Bypass -File package.ps1
```

Результат: `..\PVZ_FLOW_FINAL\PVZ_FLOW`.

## Что делает скрипт

1. Удаляет прежний `PVZ_FLOW_FINAL` и создаёт все каталоги назначения **заранее**.
   Это обязательно: `Copy-Item -Recurse` в несуществующий каталог копирует
   *содержимое* источника, а не сам каталог. При первой сборке из-за этого
   `app\dist` не попал в пакет, а `GET /` отдавал 503.
2. Копирует `launcher.mjs`, `START_PVZ_FLOW.cmd`, модули `server\*.mjs` и
   рабочую базу `data\PVZ_FLOW_DATA.sqlite`.
3. Копирует `app\dist` и `app\src` **пофайлово**, сохраняя структуру.
4. Кладёт текущий `node.exe` в `runtime\`, чтобы целевой компьютер ничего
   не устанавливал.
5. Копирует `docs\` и `data\backups\`.
6. Проверяет наличие всех обязательных файлов и завершается с ошибкой,
   если пакет неполон.

## Проверка

После сборки запустите приёмку:

```powershell
powershell -ExecutionPolicy Bypass -File verify-package.ps1
```

Он поднимает пакет на встроенном Node, прогоняет полный CRUD и удаляет
временные файлы, чтобы архив содержал чистую базу.
